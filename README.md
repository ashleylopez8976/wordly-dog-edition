# Wordly Dog Edition

A single-page dog breed photo app built with HTML, CSS, and JavaScript. Users can search for a breed and view a photo without reloading the page.

## Features

- Search for a dog breed using a form.
- Fetch and display a breed photo from the Dog API.
- Show an error message when a breed is not found or the request fails.
- Save favorite breeds in the browser using localStorage.
- Highlight a saved breed in the results.

## Data source

[Dog API](https://dog.ceo/dog-api/)

## Project files

- `index.html` — page structure and search form
- `style.css` — page design
- `script.js` — API requests, results, errors, and saved breeds

## How to use

Open `index.html` in a browser, enter a breed such as `beagle`, and click Search.
